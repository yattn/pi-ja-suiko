# 日本語推敲

1. 指定された原稿を親Piで読み、全文を `japanese_editor` の `text` に渡す。ユーザーの文体指定や変更禁止事項は `notes` に渡す。
2. 返却された推敲案と原文を比較する。数値、条件、否定、義務表現、識別子の変更は特に確認する。
3. 意味変更が疑われる箇所は報告する。問題がなくても意味保持を保証しない。

ユーザーから明示的な指示がない限り、原稿ファイルを書き換えない。ツール失敗時は結果を補ったり、別モデルへ切り替えたりしない。

原稿は外部のモデルサービスへ送信される。送信が認められていない文書には使用しない。

必要に応じて `scripts/check.py original.md revised.md` で差分を確認できる（Python 3.10以降）。
