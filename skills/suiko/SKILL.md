# 日本語推敲

1. 指定された原稿を親Piで読み、全文を `suiko` の `text` に渡す。文体の指定や変更禁止事項は `notes` に渡す。複数ファイルを扱う場合は、タイムアウトを避けるため1ファイルずつ順番に実行する。
2. 返却された推敲案と原文を比較する。数値、条件、否定、義務表現、識別子の変更は特に確認する。
3. 子Piはコードや他のファイルを参照できないため、「要確認」に挙がった直訳語や文脈依存の表現は、親Piが実装や周辺文書を確認して自然な表現に確定させる。
4. 意味変更が疑われる箇所は報告する。問題がなくても意味保持を保証しない。

READMEや利用案内では、重複や自明な説明を減らす。ただし、必要な手順・制約・重要な注意事項は残す。自然な文章は無理に変更しない。

明示的な依頼がない限り、原稿ファイルを書き換えない。ツール失敗時は結果を補ったり、別モデルに切り替えたりしない。

原稿は外部のモデルサービスへ送信される。送信が認められていない文書には使用しない。

必要に応じて `scripts/check.py original.md revised.md` で差分を確認できる（Python 3.10以降）。
